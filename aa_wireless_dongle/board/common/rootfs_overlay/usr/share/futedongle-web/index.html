Garage Door Opener (S38garage_opener)

Probes the garage Wi-Fi AP on boot (without opening on keyfob unlock) and fires the UDP trigger when the car START button is pressed via OBD-II (or on Android Auto foreground video).

Leave empty for an open network, or enter an 8–63 character WPA2 passphrase.
Sent verbatim without a trailing newline (equivalent to echo -n).
Aborts immediately to start Android Auto AP if out of garage Wi-Fi range (2–15s).
